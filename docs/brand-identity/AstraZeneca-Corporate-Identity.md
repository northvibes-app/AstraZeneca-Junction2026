# AstraZeneca Corporate Identity

As of 2026-11-13. Values taken from AstraZeneca's official website (logo file and site stylesheet). The internal brand guidelines (OnBrand) require a login and could not be read, so usage rules are not covered.

![AstraZeneca logo](AstraZeneca-Logo.jpg)

## Logo

The logo is the mixed-case wordmark "AstraZeneca" in mulberry with a gold emblem of interlocking loops at the right. Created for the April 1999 Astra–Zeneca merger, it has never been redesigned ([Logo Heritage](https://logoheritage.com/?p=3062)). The official high-resolution file (1181×286 px) is in the [AstraZeneca image library](https://www.astrazeneca.com/media-centre/image-and-broadcast-library.html); its two colours measure #830051 and #EFAB00.

| Version | Use | Source |
| --- | --- | --- |
| Full colour (mulberry + gold) | Default, on white | [Official logo file](https://www.astrazeneca.com/content/dam/az/Image%20Bank/Logos/AstraZeneca-Logo.jpg/jcr:content/renditions/original) |
| White | On dark backgrounds | Website header asset logo-az-white.png |
| Condensed (colour and white) | Narrow spaces | Website header assets logo-az-condensed*.png |

Clear space and minimum size are set in the OnBrand guidelines (login-only). The [legal notice](https://www.astrazeneca.com/legal-notice-and-terms-of-use.html) says logos may not be used without prior written consent.

## Typography

The website stylesheet sets text in Lexia, with Times as fallback, and uses a custom icon font (az-webfont). Helvetica Neue is the sans-serif fallback in some components.

| Use | Font stack (from the site CSS) |
| --- | --- |
| Body and headings | lexia, Times, "Times New Roman", serif |
| Secondary UI text | "Helvetica Neue", Helvetica, Arial, sans-serif |
| Icons | az-webfont (custom icon font) |
| Logo wordmark | Custom lettering, not an installable font |

This is the web typeface. Print and presentation fonts are in the login-only OnBrand guidelines.
